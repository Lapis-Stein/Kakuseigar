# Kakuseigar — 青娥の小説案内

質問への回答から、好みに合いそうな小説を紹介するWebアプリの開発用リポジトリです。遊びながら作品を知り、pixivの本文へ進める入口を目指しています。

本アプリは、東方Projectの非公式の二次創作です。原作：東方Project（上海アリス幻樂団／ZUN）。

[東方Projectの二次創作ガイドライン](https://touhou-project.news/guideline/)。立ち絵・背景の制作方法と配置については[素材の説明](docs/assets.md)を参照してください。

[GitHub Pagesの公開サイト](https://lapis-stein.github.io/Kakuseigar/)で遊べます。このREADMEは、このリポジトリに含まれる実装と素材を説明しています。公開への反映状況は[デプロイ履歴](https://github.com/Lapis-Stein/Kakuseigar/deployments/github-pages)で確認できます。

## ローカルで開く

Node.js 22以上で動きます。実行に追加パッケージは不要です。

```sh
node scripts/serve.mjs
```

`http://127.0.0.1:4173/Kakuseigar/` をブラウザーで開きます。JSONの読み込みを使うため、index.htmlを直接ダブルクリックする代わりに上のサーバーを利用してください。

```sh
node --test
node scripts/check.mjs
node scripts/build.mjs
```

ビルド先は `dist/` です。HTML・CSS・JavaScript・公開用データ・素材だけを書き出します。

## できること

- 読みたい話や考え方について、選択式の質問に答える。
- 作品のタイトル、推薦の前置き、作者の既存キャプションとイメージ画を見る。絵は押すと拡大する。
- pixivで本文を読む、または別の作品を探す。
- 質問の合間にランダムで提案される人物について、活躍を見たいか答える。「はい」ならその人物の作品へ進む。
- 紹介履歴を見返す。
- 同じタブで再読込して続ける、最初から遊び直す。
- 結果の共有文を確認し、Xの投稿画面を開く、または共有文とリンクをコピーする。
- 全作品を紹介してもらった実績を共有する。読了の記録とは区別する。

人格や似ているキャラクターを判定するのではなく、「この話は好みでは？」と作品を薦めるための遊びです。

人物推薦では、指定人物が主役級の作品を準主役・脇役の作品より優先し、同じ役割なら回答との一致度で選びます。上位の作品を紹介済みなら下位の作品も候補になります。

## 構成の方針

ブラウザー内で質問・推薦の処理を行い、GitHub Pagesで公開しています。診断用のサーバーや外部AIへの問い合わせは使いません。

公開するのはサイト本体と、動作に必要な確認済みデータです。本文の評価根拠や検討中の資料は、別の非公開リポジトリで管理します。

表示の設定は `data/presentation.json`。青娥の立ち絵10枚と、柔らかな昼光の書斎背景を配置しています。質問中は6種類から直前と異なる絵を選び、その設問を表示している間は固定します。名前と台詞は立ち絵の下部に重なる会話欄として表示します。`narrator.images` に `assets/` 配下の画像パス、`narrator.question_moods` に質問用の表情を設定します。立ち絵は透過WebPで表示し、作品絵は `work_art_by_work` に小表示用と拡大用の画像を登録します。[素材の配置](docs/assets.md)を参照してください。

作者のX・pixivへのリンクは画面上部のアイコン、紹介履歴・サイトの説明・遊び直しは画面下部に配置しています。結果の共有文には作品名と公開サイトの入口URLを含めます。タブ内の結果IDや回答履歴を共有URLへ含める方式ではありません。

2026年10月26日から、アクセス解析と公開集計を稼働しています。このリポジトリでは、来訪回数、直近7日間・累計の初回推薦ランキングとpixiv本文リンク利用ランキング、結果カードの今月の初回推薦数を表示する実装を管理しています。ランキングの画像から、イメージ画・タイトル・紹介文・本文リンクを開けます。変更は集計・公開ワークフローの成功後に反映されます。毎時00分の更新を設定しており、数字にはGoogle アナリティクスの処理待ちによる遅れがあります。質問操作は端末内で数え、作品紹介時に少量の概要を送ります。回答内容は送信しません。項目・通信方針・導入記録は[アクセス解析と公開集計](docs/analytics.md)を参照してください。

案内役への反応は推薦の回答・紹介履歴と独立して管理します。代理役の通常立ち絵と爆破時の画像は、作者指定の画像をWebP化したものです。名前と画像は `narrator.robot` から差し替えられます。
