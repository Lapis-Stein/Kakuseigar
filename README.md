# Kakuseigar

質問への回答から、好みに合いそうな小説を紹介するWebアプリの開発用リポジトリです。遊びながら作品を知り、pixivの本文へ進める入口を目指しています。

本アプリは、東方Projectの非公式の二次創作です。原作：東方Project（上海アリス幻樂団／ZUN）。

[東方Projectの二次創作ガイドライン](https://touhou-project.news/guideline/)。立ち絵・背景の制作方法と配置については[素材の説明](docs/assets.md)を参照してください。

ローカルで動く初期実装です。サイトの公開設定・デプロイはまだ行っていません。

## ローカルで開く

Node.js 22以上で動きます。実行に追加パッケージは不要です。

```sh
node scripts/serve.mjs
```

`http://127.0.0.1:4173/Kakuseigar/` をブラウザーで開きます。JSONの読み込みを使うため、index.htmlを直接ダブルクリックする代わりに上のサーバーを利用してください。

```sh
node --test
node scripts/check.mjs
node scripts/build.mjs
```

ビルド先は `dist/` です。HTML・CSS・JavaScript・公開用データ・素材だけを書き出します。

## できること

- 読みたい話や考え方について、選択式の質問に答える。
- 作品のタイトル、推薦の前置き、作者の既存キャプションを見る。
- pixivで本文を読む、または別の作品を探す。
- 質問の合間にランダムで提案される人物について、活躍を見たいか答える。「はい」ならその人物の作品へ進む。
- 紹介履歴を見返す。
- 同じタブで再読込して続ける、最初から遊び直す。
- 結果の共有シート、または共有文のコピーを使う。

人格や似ているキャラクターを判定するのではなく、「この話は好みでは？」と作品を薦めるための遊びです。

## 構成の方針

ブラウザー内で質問・推薦の処理を行い、GitHub Pagesでの公開を想定しています。診断用のサーバーや外部AIへの問い合わせは前提にしません。

公開するのはサイト本体と、動作に必要な確認済みデータです。本文の評価根拠や検討中の資料は、別の非公開リポジトリで管理します。

表示の設定は `data/presentation.json`。青娥の立ち絵10枚と、柔らかな昼光の書斎背景を配置しています。質問中は6種類から直前と異なる絵を選び、その設問を表示している間は固定します。名前と台詞は立ち絵の下部に重なる会話欄として表示します。`narrator.images` に `assets/` 配下の画像パス、`narrator.question_moods` に質問用の表情を設定します。[素材の配置](docs/assets.md)を参照してください。

2026年10月22日、作者から提示されたpixivの既存キャプション10本を登録しました。作者の文章と改行をそのまま保持し、診断用の推薦文とは別に「作者による紹介」として表示します。結果カードの登場人物一覧は引き続き未登録です。人物質問は公開用データの対象人物から選び、画面に登場済みであることは条件にしません。

設計とデータの境界は[構成方針](docs/architecture.md)、このリポジトリで作業する際の注意は[AGENTS.md](AGENTS.md)を参照してください。
